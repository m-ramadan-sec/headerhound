# Roadmap

This is a guide, not a promise. Work is prioritized by validated user need and maintainability.

## Near term

- Add fixtures for real-world header syntax and expand browser-compatibility tests.
- Document score rationale and provide a documented configuration file for organization-specific policy baselines.
- Add optional SARIF output only if it provides clear CI value.

## Later

- Improve reporting for redirect-chain header regressions.
- Add release automation with provenance after a stable packaging workflow is established.
- Review accessibility and shell-completion needs based on contributor feedback.

We will not add crawling, exploitation, or evasive behavior.
