# Security Policy

## Supported versions

Security fixes are applied to the latest released version and the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it privately to the repository owner through GitHub's private vulnerability reporting feature, if enabled, or use the contact details published on the maintainer's GitHub profile. Include reproduction steps, impact, affected version, and any proposed mitigation.

We aim to acknowledge reports within 7 days and provide a status update within 30 days. Please do not access data, disrupt services, or scan systems without authorization while researching an issue.
